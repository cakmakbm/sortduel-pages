# sortduel-pages

The privacy policy and support page for the Sort Duel iOS app, hosted on GitHub Pages
because the App Store requires both to be publicly reachable without an account.

Public on purpose, and separate from the game's own repository on purpose: the game is
private, and making it public to serve two static pages would publish the source as well.

The originals live in `store/` in the app repository. Edit them there and copy them here.
